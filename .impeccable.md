## Design Context

### Users
Carelo is for developers and power users who manage many local and remote files from the desktop. Their core jobs are finding known files quickly, rediscovering files by metadata or content, moving and comparing data across panes, and completing complex file operations without losing flow. Keyboard access, fast feedback, and trustworthy state matter more than decorative presentation.

### Brand Personality
Fast, composed, capable. Carelo should create confidence through precise behavior and clear status while feeling calm under heavy workloads. Its voice is concise and action-oriented.

### Aesthetic Direction
Use a dense, refined, desktop-native visual language that fits Carelo's existing macOS-inspired utility chrome without imitating Finder. Preserve the compact information hierarchy, warm-tinted neutral surfaces, restrained system-blue accent, fine separators, and support for light, dark, system, and named color themes. The interface should feel purpose-built for sustained work, not like a card-based web dashboard.

### Design Principles
1. Keep the common path immediate, then reveal advanced controls progressively.
2. Prefer information density with strong hierarchy over oversized controls or decorative space.
3. Make every operation feel trustworthy through explicit scope, progress, results, and recovery states.
4. Treat keyboard and pointer workflows as equally complete; preserve visible focus and reduced-motion behavior.
5. Reuse Carelo's theme tokens and interaction patterns so new tools feel native to the application.
